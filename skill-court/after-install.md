# Skill Court is installed

Automatic trials are **off**. Once turned on, Skill Court replays tasks with and without each skill
the agent writes, in the background, on your provider account: up to $1.00 a day of replays and
300,000 judge tokens (change them with `--budget` and `--judge-tokens`). Spending that is the
user's choice, so an agent that installed this plugin asks the user before turning it on.

- Turn on: `hermes court auto on`, or **Turn on…** on the Skill Court page in Hermes Desktop
- Test one skill now: `hermes court trial <skill>`
- See verdicts: `hermes court report`
